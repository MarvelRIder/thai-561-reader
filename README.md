# เปิดอ่าน 56-1 One Report

พิมพ์ชื่อย่อหุ้นไทย (เช่น `PTT`, `CPALL`, `AOT`) แล้วเว็บแอปจะ:

1. ค้นหาชื่อเต็มบริษัทจาก Yahoo Finance (ตาม symbol `.BK`)
2. จับคู่ชื่อกับฐานข้อมูลแบบ 56-1 One Report ของสำนักงาน ก.ล.ต. (`market.sec.or.th`, ระบบเปิดเผยข้อมูลสาธารณะ)
3. ดาวน์โหลดไฟล์ zip ที่บริษัทยื่นไว้ แตกไฟล์ และสตรีม PDF ให้เปิดอ่านได้ทันทีในเบราว์เซอร์
   — ผู้ใช้ไม่ต้องกดดาวน์โหลดหรือแตก zip เอง

## วิธีรัน

```bash
npm install
node server.js
```

แล้วเปิด http://localhost:3000

## ข้อควรรู้ / ข้อจำกัด

- ข้อมูลรายชื่อบริษัททั้งหมด (~4,000 รายการ) โหลดจากหน้า SEC สาธารณะและแคชไว้ 6 ชั่วโมง
- ไฟล์ zip แต่ละไฟล์แคชไว้ 30 นาที (สูงสุด 15 ไฟล์ล่าสุด) เพื่อลดการโหลดซ้ำ
- การจับคู่ชื่อบริษัทใช้ fuzzy matching (token overlap) — ถ้าไม่ตรง 100% แอปจะแสดงตัวเลือกใกล้เคียงให้กดเลือกแทน
- บางบริษัทมีเอกสารแนบมากกว่า 1 ไฟล์ (เช่น "โครงสร้างบริษัท") — แอปจะแสดงลิงก์เอกสารแนบทั้งหมดให้เลือกเปิดเพิ่มได้
- ข้อมูลทั้งหมดมาจากเว็บไซต์เปิดเผยข้อมูลสาธารณะของ ก.ล.ต. (`market.sec.or.th/public/idisc`) ไม่ได้ใช้ API แบบเสียเงินหรือ bypass ระบบป้องกันใด ๆ
